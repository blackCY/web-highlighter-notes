# Web Highlighter Notes

一个基于 Chrome Manifest V3 的本地网页笔记扩展：对网页文字作不同等级的**背景色包裹标记**，记录图片、视频和音频，并将内容导出为 Markdown。

## 功能

- 在任意 `http` 或 `https` 网页选中文字，点击浮动工具栏中的「重要 / 想法 / 疑问 / 复习」完成背景色高亮。
- 在选中文字上右键，可从「保存为网页笔记」菜单选择标记等级。
- 点击图片、视频或音频，选择「记录此媒体」保存媒体类型、标题与地址。
- 使用 `chrome.storage.local` 按网页 URL 在浏览器本地保存；刷新同一页面后，静态内容上的高亮会自动恢复。
- 点击工具栏图标打开笔记面板，可为每项添加自己的备注，或清除当前页记录。
- 一键导出 `.md`，内含原文标题、网址、各项标记、媒体地址与备注。

## 安装

1. 克隆本仓库，或下载源码。
2. 打开 Chrome 的 `chrome://extensions`。
3. 开启右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择本仓库目录。

## 限制

- 数据仅保存在当前 Chrome 配置文件中，卸载扩展或清除扩展数据会丢失记录。
- 页面大幅调整 DOM 后，之前的文字定位可能无法恢复；媒体记录和导出的笔记不受影响。
- Chrome 出于安全限制，不能在浏览器内部页面、Chrome Web Store 等受保护页面中注入扩展。

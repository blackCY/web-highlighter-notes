# Web Highlighter Notes

一个基于 Chrome Manifest V3 的本地网页笔记扩展：对网页文字作不同等级的**背景色包裹标记**，记录图片、视频和音频，并将内容导出为 Markdown。

## 功能

- 在任意 `http` 或 `https` 网页选中文字，点击浮动工具栏中的「重要 / 想法 / 疑问」完成背景色高亮；悬停「重要」可选红、绿、橙三种背景色。
- 「默认 / 加粗」可直接记录当前所选文字；网页内会显示灰色背景，默认权重显示细下划线、加粗权重显示粗下划线并加粗文字，导出的 Markdown 使用 `**文字**`。
- 选择「想法」或「疑问」时，工具栏上方会出现输入框；填写内容后会显示在对应高亮下方，并作为该标记的子节点导出，以蓝色背景白字显示「我的想法」或「我的疑问」。输入时按 `Cmd/Ctrl + Enter` 可快速保存。
- 同一段文字可以分别保存「我的想法」和「我的疑问」；两类内容独立编辑、独立显示，并会同时作为 Markdown 子节点导出。
- 网页中的每条文字标记上方会显示对应的类型气泡，例如「重要」「想法」「疑问」「默认」或「加粗」。
- 同一处标记可累积显示多个类型气泡；例如先标记默认、再标记加粗时，两个气泡都会保留。
- 工具栏的「标题」支持 H1 到 H6；网页原文保留原有字号和样式，并使用紫色背景与对应 H1–H6 类型气泡标识。导出时按网页从上到下的标题顺序生成 Markdown 章节，位于标题后的笔记自然归入该标题层级。
- 点击已有高亮会再次打开工具栏，可修改它的等级、背景色和权重。
- 点击已有高亮后，工具栏会显示「删除笔记」；二次确认后会移除网页标记、关联气泡和本地记录。
- 在选中文字上右键，可从「保存为网页笔记」菜单选择重要、想法、疑问、标题 H1–H6、默认笔记或加粗笔记；选择想法或疑问时会打开输入框。
- 点击图片、视频或音频，选择「记录此媒体」保存媒体类型、标题与地址。
- 已记录的媒体左上角会显示「已记录」浮动气泡；页面滚动、缩放和刷新后气泡会跟随并恢复。
- 笔记会同步到配置的 GitHub 仓库，以“网页标题 + 稳定哈希”的 Markdown 文件保存；favicon 写入 YAML Front Matter，正文一级标题仅显示网页标题。原文网址、favicon 和更新时间也位于 YAML Front Matter。同一网页会忽略 URL 中的 `?` 查询参数和 `#` 锚点，因此刷新、切换锚点或移除追踪参数后仍可恢复。
- 新建文字或标题标记会在 GitHub 同步成功后才显示在网页中；网络或 Token 异常不会留下无法再次编辑的假高亮。
- 文字恢复优先使用带 ID 的页面区域定位，缺少 ID 时使用元素类名与原文上下文；动态页面插入正文后会自动再次尝试恢复。
- 点击已有网页高亮后，可在工具栏中选择「备注」添加或编辑自己的备注；扩展弹窗仅用于浏览、筛选和管理本页笔记。「强制删除」需要二次确认，并会同时清理 GitHub 中新旧两种文件名的当前页笔记。
- 弹窗顶部支持按摘录、媒体标题、地址或个人备注筛选当前页面的笔记。
- 当其他设备或标签页修改了同一网页的笔记时，可点击弹窗底部「从 GitHub 刷新」拉取最新记录并刷新当前网页。
- 一键下载 `.md`，内含原文标题、网址、各项标记、媒体地址与备注；内容按网页中的前后顺序排列，重要、想法和疑问使用深色背景与白色文字呈现，想法/疑问仅在填写了自己的内容时输出子节点。

## 安装

1. 克隆本仓库，或下载源码。
2. 打开 Chrome 的 `chrome://extensions`。
3. 开启右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择本仓库目录。

## 配置 GitHub 笔记同步

1. 打开扩展弹窗，点击右上角的「GitHub」。
2. 填写目标仓库、分支和笔记目录；默认仓库为本项目的 `blackCY/web-highlighter-notes`，默认目录为 `notes/`。
3. 创建 Fine-grained Personal Access Token，仅授权目标仓库，并授予 `Contents` 的读写权限。
4. 将 Token 粘贴到配置中并保存；扩展会先验证仓库与分支访问权限，验证通过后再保存。然后刷新网页。

Token 仅保存在当前 Chrome 配置文件的扩展存储中，不会写入仓库。笔记内容、原文网址和个人备注会写入 GitHub，因此建议使用私有仓库。

## 下载 Markdown

点击扩展弹窗底部「导出 Markdown」后，浏览器会直接下载当前页面的笔记文件，无需启动本地服务。下载文件使用当前网页标题命名，默认位于浏览器的下载目录；扩展不会主动打开保存位置选择框。

## 限制

- 未配置有效 GitHub Token 时，无法创建、编辑或恢复笔记。
- 页面删除原文、修改原文或同时存在大量完全相同文本时，文字定位仍可能无法恢复；媒体记录和导出的笔记不受影响。
- Chrome 出于安全限制，不能在浏览器内部页面、Chrome Web Store 等受保护页面中注入扩展。

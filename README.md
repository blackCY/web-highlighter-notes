# Web Highlighter Notes

一个基于 Chrome Manifest V3 的本地网页笔记扩展：对网页文字作不同等级的**背景色包裹标记**，记录图片、视频和音频，并将内容导出为 Markdown。

## 功能

- 在任意 `http` 或 `https` 网页选中文字，点击浮动工具栏中的「重要 / 想法 / 疑问」完成背景色高亮；悬停「重要」可选红、绿、橙三种背景色。
- 可在菜单中切换「默认 / 加粗」笔记权重；网页内默认权重显示细下划线、加粗权重显示粗下划线并加粗文字，导出的 Markdown 使用 `**文字**`。
- 选择「想法」或「疑问」时，工具栏上方会出现输入框；填写内容后会显示在对应高亮下方，并作为该标记的子节点导出，以淡蓝色背景显示「我的想法」或「我的疑问」。
- 点击已有高亮会再次打开工具栏，可修改它的等级、背景色和权重。
- 在选中文字上右键，可从「保存为网页笔记」菜单选择标记等级。
- 点击图片、视频或音频，选择「记录此媒体」保存媒体类型、标题与地址。
- 已记录的媒体左上角会显示「已记录」浮动气泡；页面滚动、缩放和刷新后气泡会跟随并恢复。
- 使用 `chrome.storage.local` 按网页 URL 在浏览器本地保存；刷新同一页面后，静态内容上的高亮会自动恢复。
- 点击工具栏图标打开笔记面板，可为每项添加自己的备注，或清除当前页记录。
- 一键导出 `.md`，内含原文标题、网址、各项标记、媒体地址与备注；内容按网页中的前后顺序排列，重要标记使用带背景色的 HTML 呈现。首次导出以 `网站域名-YYYYMMDD-HHMMSS.md` 命名，之后同一原文网址会更新该文件。

## 安装

1. 克隆本仓库，或下载源码。
2. 打开 Chrome 的 `chrome://extensions`。
3. 开启右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择本仓库目录。

## 启动本地导出服务

Chrome 扩展不能自行写入电脑上的项目目录，因此导出前需在本项目根目录运行以下命令，并保持终端开启：

```bash
npm run exporter
```

扩展会将 Markdown 发送到本地服务，服务会将其写入本项目的 `exports/` 目录。

也可以双击 `start-exporter.command`，它会自动打开终端并启动同一个服务。只要该终端窗口保持运行，插件便可以导出。

## 限制

- 数据仅保存在当前 Chrome 配置文件中，卸载扩展或清除扩展数据会丢失记录。
- 页面大幅调整 DOM 后，之前的文字定位可能无法恢复；媒体记录和导出的笔记不受影响。
- Chrome 出于安全限制，不能在浏览器内部页面、Chrome Web Store 等受保护页面中注入扩展。
- 本地导出服务未启动时，扩展会提示启动命令，且不会导出文件。
